# sieniawski.co.uk

Landing page for [sieniawski.co.uk](https://sieniawski.co.uk/). A React + Vite single-page app, deployed to GitHub Pages on every push to `main`.

## Editing content

All copy — name, location, skills, contact — lives in [`src/data.ts`](src/data.ts). Edit that file and push; nothing else needs to change.

## Development

Requires Node.js `^20.19.0` or `>=22.12.0`.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
